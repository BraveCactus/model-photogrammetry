# model-photogrammetry

Проект для модели двухосевого ОПУ.

## Запуск

```matlab
cd('D:\My\Projects\diplom\photogram\model\photo_opu')
run_render('preview')   % 60 кадров, cam1, 50 %, быстро
run_render('full')      % все 301 кадр, cam1..cam3, 100 %
```

`run_render` последовательно выполняет:

1. экспорт `scene.json`, `animation.csv`, `ground_truth`;
2. сборку сцены Blender;
3. создание анимации;
4. рендер PNG;
5. сборку MP4 через MATLAB `VideoWriter`.

Результаты: `output/frames/<run_id>/camX/` и `output/videos/<run_id>/camX.mp4`.

## Модель

Четыре тела Simscape:

| Тело | Геометрия | Начальное положение |
|---|---|---|
| `Stator` | цилиндр Ø320 × 100 мм | центр `[0, 0, 0.05]` |
| `RightCol` | плита 160 × 30 × 300 мм | центр `[0, +0.16, 0.25]` |
| `LeftCol` | плита 160 × 30 × 300 мм | центр `[0, -0.16, 0.25]` |
| `Rotor` | площадка 340 × 400 × 50 мм | центр `[0, 0, 0.48]` |

## Маркеры

6 маркеров ArUco `DICT_4X4_50`, сторона 30 мм, белая рамка 20 %:

| ID | Где | Нормаль |
|---|---|---|
| 0 | верхняя площадка, `[-0.085, -0.09, +0.0252]` | `+Z` |
| 1 | верхняя площадка, `[+0.085, -0.09, +0.0252]` | `+Z` |
| 2 | верхняя площадка, `[+0.085, +0.09, +0.0252]` | `+Z` |
| 3 | верхняя площадка, `[-0.085, +0.09, +0.0252]` | `+Z` |
| 4 | торец `+Y`, `[0, +0.2002, 0]` | `+Y` |
| 5 | торец `-Y`, `[0, -0.2002, 0]` | `-Y` |

Маркеры заданы в системе координат тела `Rotor` в `params_markers.m`.
Текстуры: `sim2blender/textures/aruco_00.png … aruco_05.png`.

## Камеры

Три камеры, 2448 × 2048, пиксель 3.45 мкм, фокус 16 мм:

| Камера | Позиция, м |
|---|---|
| `cam1` | `[1.35, -1.15, 1.40]` |
| `cam2` | `[1.35, 0.00, 1.45]` |
| `cam3` | `[1.35, +1.15, 1.40]` |

Все камеры направлены в точку `[0, 0, 0.30]`.
